Wi-Fi 비밀번호를 정확히 입력했다고 생각하는데도 '암호가 올바르지 않음', '이 네트워크에 연결할 수 없음', '인증 오류'가 나타나나요? **비밀번호가 실제로 틀린 경우**와 **비밀번호는 맞지만 기기·공유기의 인증 설정이 맞지 않는 경우**를 구분해야 합니다. 처음부터 공유기를 공장 초기화하거나 보안 기능을 끄는 것은 적절한 해결 방법이 아닙니다.

이 글은 가정용 Wi-Fi에 연결할 때 발생하는 문제를 중심으로 Windows 11, iPhone·iPad, Mac, Android의 점검 경로를 설명합니다. 회사·학교·호텔의 로그인 방식은 별도로 구분합니다. 메뉴 이름은 운영체제와 공유기 모델에 따라 달라질 수 있습니다. 여기 나온 절차는 제조사 공식 문서를 토대로 정리했으며 모든 기기 조합을 실물에서 시험했다는 뜻은 아닙니다.

## 먼저 증상을 4가지로 구분하기

| 화면에 보이는 현상 | 먼저 확인할 문제 | 무작정 하면 안 되는 작업 |
| --- | --- | --- |
| '암호가 올바르지 않음' 반복 | 실제 암호, 네트워크 이름, 저장된 연결 정보 | 공유기 공장 초기화 |
| '이 네트워크에 연결할 수 없음' | 보안 방식·기기 호환성·무선 어댑터 | 보안 끄기, WEP 사용 |
| Wi-Fi에는 연결됐지만 '인터넷 없음' | IP·회선·DNS·인터넷 접속 | 암호를 계속 바꾸기 |
| 카페·호텔에서 연결됐지만 웹 이용 불가 | 포털 로그인·이용 약관·접속 정책 | 관리 페이지가 아닌 임의 사이트에 비밀번호 입력 |

마지막 두 증상은 Wi-Fi 인증 실패와 다릅니다. 네트워크 이름 옆에 '연결됨'이 표시되고 내부 연결이 성립했다면 기존 비밀번호를 반복 입력하기보다 인터넷 서비스·로그인 화면 문제를 점검해야 합니다. 반대로 네트워크에 아예 연결되지 않는다면 아래 인증 관련 단계부터 시작하세요.

## 1. 내가 접속하려는 네트워크가 맞는지 확인

먼저 Wi-Fi 목록에 표시된 **네트워크 이름(SSID)**이 정확한지 확인하세요. 공유기가 두 대이거나 이웃집과 이름이 비슷한 경우, 다른 네트워크에 암호를 입력하고 있을 수 있습니다.

1. 공유기 관리자 앱 또는 가족이 현재 정상적으로 접속해 사용하는 기기에서 실제 네트워크 이름을 확인합니다.
2. 2.4GHz와 5GHz가 다른 이름으로 분리돼 있다면 각각 어떤 네트워크인지 확인합니다.
3. 이름이 같아도 전혀 다른 공유기일 수 있으므로 본인이 관리하거나 이용 권한이 있는 네트워크인지 확인합니다.
4. 회사·학교의 관리형 Wi-Fi는 네트워크 관리자가 안내한 이름과 로그인 방법을 따릅니다.

Apple은 라우터에 고유한 SSID를 사용하고, 가능하면 모든 대역에서 일관된 이름을 사용하도록 권장합니다. **연결 문제를 해결하겠다며 여러 대역의 이름을 무조건 바꿀 필요는 없습니다.** 이름을 변경하면 가족의 기기를 다시 연결해야 할 수도 있습니다.

## 2. Wi-Fi 암호와 공유기 관리자 암호 구분하기

공유기에는 대개 **Wi-Fi에 접속하는 암호**와 **관리자 설정 화면에 로그인하는 암호**가 별도로 존재합니다. 또 공유기 바닥의 스티커에는 출고 당시 초기 암호가 적혀 있을 수 있는데, 설치 기사가 변경했거나 사용자가 직접 바꿨다면 초기 암호로는 연결되지 않습니다.

- 암호의 **영문 대소문자**를 정확히 구분합니다.
- 숫자 0과 알파벳 O, 숫자 1과 소문자 l을 혼동하지 않았는지 살펴봅니다.
- 입력 언어·키보드 배열·불필요한 공백이 섞이지 않았는지 확인합니다.
- 가족이 암호를 최근 변경했는지 확인합니다.
- 비밀번호를 공개 댓글이나 낯선 진단 사이트에 입력하지 않습니다.

휴대폰에서 Wi-Fi 암호를 QR 코드로 공유할 수 있는 경우에도 **상대 기기가 신뢰할 수 있는 기기인지** 확인하세요. Android 공식 도움말은 Wi-Fi 설정에서 QR 코드로 네트워크 정보를 공유하는 절차를 안내합니다. QR 코드는 사실상 접속 정보를 포함할 수 있으므로 공개 사진이나 게시물에 올리지 마세요.

## 3. 다른 기기에서도 똑같은 오류가 나는지 비교하기

가장 유용한 진단은 같은 장소에서 **두 기기를 같은 SSID에 연결하는 비교**입니다.

1. Wi-Fi가 정상 작동하던 다른 휴대폰이나 노트북이 있는지 확인합니다.
2. 기존에 접속된 기기의 연결을 불필요하게 끊지 말고 새 기기의 연결만 시험합니다.
3. 다른 기기는 정상인데 한 대만 실패한다면 그 기기의 저장된 설정이나 호환성을 먼저 점검합니다.
4. 새 기기가 모두 실패한다면 최근 변경된 공유기 암호·인증 방식·접속 제한을 확인합니다.
5. 모든 기기가 Wi-Fi에는 연결되지만 인터넷이 안 된다면 통신사·모뎀·라우터의 외부 회선 쪽으로 진단을 바꿉니다.

이 비교만으로 결함 부품을 확정할 수는 없습니다. 예를 들어 기존 기기가 한동안 연결을 유지해도 새 기기 인증에 필요한 공유기 설정에는 문제가 있을 수 있습니다. **다른 기기도 안 된다 = 공유기 고장**으로 단정하지 마세요.

## 4. Windows 11: 저장된 네트워크를 지우고 재연결하기

공유기 암호를 바꿨거나 Windows가 예전 연결 설정을 계속 사용한다면 저장된 Wi-Fi 프로필을 삭제한 뒤 새로 연결하는 방법이 있습니다. 다만 이 작업을 하면 해당 네트워크의 저장된 암호를 다시 입력해야 합니다.

1. 현재 Wi-Fi 비밀번호를 확실히 알고 있는지 먼저 확인합니다.
2. **시작 → 설정 → 네트워크 및 인터넷 → Wi-Fi**로 이동합니다.
3. **알려진 네트워크 관리**를 엽니다.
4. 문제가 발생하는 SSID에서 **삭제(잊어버리기)**를 선택합니다.
5. 다시 사용 가능한 Wi-Fi 목록에서 같은 SSID를 찾아 선택합니다.
6. 현재의 올바른 암호를 입력한 뒤 연결 상태를 확인합니다.

Windows 11은 **도움말 보기(Get Help)** 앱에서 네트워크 및 인터넷 문제 해결사를 실행할 수도 있습니다. 단, 학교·회사에서 배포한 인증서와 Wi-Fi 프로필을 사용하는 기기는 임의로 삭제하기 전에 IT 담당자에게 문의하세요. Microsoft는 일반 Wi-Fi 연결 문제의 점검 절차에 저장된 네트워크 삭제 및 재연결을 포함합니다.

**중요:** 이 단계는 특정 SSID를 지우는 작업입니다. Windows의 **전체 네트워크 초기화**와 다릅니다. 전체 초기화는 VPN, 가상 네트워크 어댑터 등 다른 네트워크 설정에도 영향을 줄 수 있으므로 마지막 수단으로 두세요.

## 5. iPhone·iPad: 해당 Wi-Fi 네트워크 지우기

Apple은 이전에 접속했던 Wi-Fi 네트워크에서 문제가 생겼을 때 해당 네트워크를 지운 뒤 다시 연결하는 방법을 안내합니다. 그러나 **iCloud 키체인을 함께 쓰는 Apple 기기에서는 한 기기의 네트워크 삭제가 다른 기기에도 적용될 수 있습니다.** 이 점을 먼저 확인하세요.

1. **설정 → Wi-Fi**를 엽니다.
2. 현재 연결된 네트워크라면 옆의 정보 버튼을 눌러 설정을 확인합니다.
3. 과거에 연결했던 네트워크는 **편집**에서 알려진 네트워크 목록을 확인할 수 있습니다.
4. 해당 네트워크의 **이 네트워크 지우기**를 선택합니다.
5. 다시 같은 SSID를 선택하고 현재 비밀번호를 입력합니다.
6. 연결되면 파란색 체크 표시가 있는지 확인합니다.

학교나 직장에서 관리하는 네트워크는 삭제 옵션이 없거나 관리형 프로필에 의해 다시 설치될 수 있습니다. 이 경우 억지로 삭제하려 하지 말고 관리자에게 문의하세요. **전체 네트워크 설정 재설정은 여기보다 훨씬 큰 조치**이므로 아직 진행하지 않습니다.

## 6. Mac·Android에서 네트워크 다시 연결하기

**Mac:** 최근 macOS에서는 **Apple 메뉴 → 시스템 설정 → Wi-Fi → 고급**에서 알려진 네트워크를 확인할 수 있습니다. 해당 네트워크의 추가 옵션에서 **목록에서 제거**를 선택하고 다시 연결합니다. 현재 연결 상태나 macOS 버전에 따라 세부 메뉴가 다를 수 있습니다. iCloud 키체인으로 Wi-Fi 정보를 동기화한다면 다른 Apple 기기에 미칠 영향도 먼저 고려하세요.

**Android:** Google의 기본 안내는 **설정 → 네트워크 및 인터넷 → 인터넷**에서 저장된 네트워크를 확인하고, 해당 네트워크를 길게 터치해 **삭제(Forget)**하는 방식입니다. 기종에 따라 '연결 → Wi-Fi' 등 메뉴가 다를 수 있으므로 삼성전자 등 제조사의 안내를 우선 확인하세요.

공통적으로 해당 네트워크를 삭제하면 **저장된 접속 정보가 지워져 비밀번호를 다시 입력해야 합니다.** 현재 암호를 모르는 상태에서 삭제하는 것은 피하세요. 다른 Wi-Fi에서 정상 연결되는지도 확인하면 문제 범위를 좁히는 데 도움이 됩니다.

## 7. WPA3·WPA2 보안 방식의 호환성 점검

암호가 맞는데도 특정 오래된 노트북·TV·스마트 기기만 연결되지 않는다면 공유기와 기기의 **Wi-Fi 보안 인증 방식**을 확인해 볼 필요가 있습니다.

| 공유기 보안 방식 | 일반적인 판단 | 권장 조치 |
| --- | --- | --- |
| WPA3-Personal | 지원 기기에 높은 보안 수준 | 기기·메쉬 노드의 지원 여부 확인 |
| WPA2/WPA3 전환형 | 최신 기기와 일부 구형 기기의 공존에 유리 | 호환성 문제 시 공식 권장 설정 검토 |
| WPA2-Personal(AES) | WPA3 호환이 어려운 구형 기기용 선택지 | 필요 시 제조사 지침에 따라 검토 |
| WPA/WPA2 혼합, WEP, TKIP | 보안상 취약하거나 권장되지 않음 | 문제 해결을 위해 활성화하지 않음 |
| 암호 없음(Open) | 무선 통신 보호에 취약 | 임시 진단 목적이라도 사용하지 않음 |

Apple은 **WPA3-Personal**을 권장하며 구형 기기의 호환성이 필요하다면 **WPA2/WPA3 전환형**을 권장합니다. ASUS는 일부 구형 기기와 메쉬 노드에서 WPA3 인증 호환성 문제가 생길 수 있다고 설명합니다.

따라서 WPA3만 설정한 후 새 기기 연결이 실패한다면 **모든 장비가 해당 보안 방식을 지원하는지** 확인하세요. 문제를 해결한다며 WEP나 TKIP로 보안을 낮추지 마세요. 설정을 꼭 바꿔야 한다면 공유기 설정을 백업하고, 관리자 권한이 있는 사람이 공식 설명서에 따라 진행해야 합니다.

설정 변경 시 다른 가족의 기기도 재연결을 요구받을 수 있습니다. 중요한 업무·화상회의가 진행 중일 때 공유기 보안 설정을 변경하지 마세요.

## 8. 연결 제한·게스트 네트워크·회사 인증 방식 확인

공유기 관리자 앱에 **접속 허용 목록, 기기 차단 목록, MAC 주소 필터링** 같은 기능이 있다면 새 기기가 제한 대상인지 확인합니다. Apple은 MAC 주소 필터링만으로 Wi-Fi 보안을 확보하지 말라고 권장하며, 일부 기기의 비공개 Wi-Fi 주소가 네트워크마다 달라질 수 있음을 설명합니다.

다만 문제 해결을 위해 **비공개 Wi-Fi 주소 기능을 무작정 끄거나 전체 접근 제어를 해제할 필요는 없습니다.** 본인 공유기인지, 해당 기기를 허용해야 하는지, 회사 관리 정책이 있는지를 먼저 확인하세요.

또한 모든 Wi-Fi가 하나의 비밀번호로 연결되는 것은 아닙니다.

- **가정용 WPA2/WPA3-Personal**은 일반적으로 공유된 네트워크 암호를 사용합니다.
- **회사·학교 Wi-Fi**는 개인 계정, 인증서, 관리 프로필 등의 별도 인증을 요구할 수 있습니다.
- **카페·호텔 Wi-Fi**는 연결 이후 웹 로그인 화면이나 이용 약관을 거쳐야 할 수 있습니다.
- **게스트 네트워크**는 본래의 가정용 SSID와 다른 암호 또는 접속 정책을 사용할 수 있습니다.

학교·회사 네트워크라면 인증서 검증이나 보안 정책을 우회하지 마세요. 접속 오류 메시지와 기기 모델·OS 버전만 기록해 공식 IT 지원 채널에 문의하세요. 비밀번호·전체 인증서 내용은 불필요하게 공유하지 않습니다.

## 9. 재시작·펌웨어 점검 후에도 안 될 때

여기까지 했는데도 새 기기들이 연결되지 않으면 라우터와 기기의 상태를 확인합니다.

1. 먼저 문제가 있는 기기의 Wi-Fi를 껐다가 켜거나 **기기를 재시작**합니다.
2. 가족이 사용 중인 인터넷에 영향이 없는 시간에 공유기와 모뎀의 **정상적인 전원 재시작**을 고려합니다.
3. 공유기 제조사 공식 관리 앱에서 펌웨어 업데이트가 필요한지 확인합니다.
4. 지원되는 보안 방식, 관리형 접속 제한, 저장된 프로필을 다시 대조합니다.
5. **한 번에 한 설정만** 바꾼 뒤 같은 네트워크에서 재연결을 확인합니다.
6. 해결되지 않으면 공유기 모델, 단말 모델, 오류 메시지, 발생 시점, 다른 기기의 성공·실패 여부를 기록합니다.

**공유기 공장 초기화**는 인터넷 접속 방식, 관리자 계정, Wi-Fi 암호, 게스트 네트워크 및 메쉬 설정을 지울 수 있습니다. 초기화를 꼭 해야 하는 상황이라면 관리 권한, 현재 설정 백업, 복구 절차를 확보하고 제조사 또는 통신사 지원을 받으세요.

**iPhone의 네트워크 설정 재설정**도 해당 SSID 하나만 지우는 작업과 다릅니다. Apple은 이것이 모든 Wi-Fi 네트워크와 암호, 셀룰러 설정, VPN 및 APN 설정에 영향을 준다고 설명합니다. 다른 해결책이 효과가 없을 때만 고려하고, 회사·학교 기기는 IT 담당자와 상의하세요.

Windows 전체 네트워크 초기화 역시 모든 연결에 영향을 줄 수 있어, 특정 비밀번호 오류의 첫 해결책이 아닙니다.

## 해결 여부 확인 체크리스트

- [ ] 연결하려는 SSID가 정확하다.
- [ ] 공유기의 **현재** Wi-Fi 암호를 확인했다.
- [ ] 관리자 암호와 Wi-Fi 암호를 혼동하지 않았다.
- [ ] 다른 기기로 동일한 SSID에 연결해 비교했다.
- [ ] 필요한 경우에만 문제가 되는 네트워크 프로필을 지웠다.
- [ ] 새 암호를 입력한 뒤 연결 상태를 확인했다.
- [ ] 공유기의 보안 수준을 WEP·TKIP·Open으로 낮추지 않았다.
- [ ] 회사·학교 네트워크 정책을 임의로 우회하지 않았다.
- [ ] 인터넷 사용이 정상이고 다른 가족 기기의 연결도 유지된다.
- [ ] 공장 초기화 없이 원인 범위를 충분히 좁혔다.

네트워크 인증 성공 여부는 Wi-Fi 아이콘과 연결 상태에서, 인터넷 연결 성공 여부는 서로 다른 웹사이트 및 앱 접속으로 따로 확인하세요. 연결만 되었다고 실제 인터넷까지 정상이라는 뜻은 아닙니다.

## 자주 묻는 질문

### Q. 비밀번호가 맞는데 왜 '암호가 올바르지 않다'고 나오나요?

다른 SSID를 선택했거나 공유기 암호가 변경됐을 수 있고, 저장된 연결 정보 또는 보안 방식 호환성 문제일 수도 있습니다. 오류 문구만으로 원인을 확정할 수는 없습니다. **현재 암호 확인 → 다른 기기 비교 → 해당 네트워크 다시 연결** 순서가 안전합니다.

### Q. 공유기 스티커의 비밀번호를 입력해도 안 돼요.

스티커는 출고 기본 정보를 표시할 수 있습니다. 설치 후 비밀번호가 변경됐다면 현재 암호와 다릅니다. 관리자 계정 비밀번호와도 혼동하지 마세요. 현재 설정을 관리하는 사람이나 통신사·제조사 공식 지원 채널에서 확인하세요.

### Q. Wi-Fi 네트워크를 삭제하면 사진이나 앱도 삭제되나요?

특정 Wi-Fi 네트워크를 '잊어버리기' 하면 일반적으로 해당 네트워크의 저장된 접속 정보가 삭제됩니다. 사진이나 앱 삭제 기능이 아닙니다. 다만 iCloud 키체인으로 동기화하는 다른 Apple 기기에도 삭제가 반영될 수 있습니다.

### Q. WPA3를 끄면 무조건 해결되나요?

그렇지 않습니다. 특정 구형 기기의 인증 호환성이 원인인 경우에만 보안 방식 변경이 도움이 될 수 있습니다. 지원 장비를 확인하고, 필요하다면 WPA2/WPA3 전환형 등 공식 권장 설정을 검토하세요. **암호화 자체를 끄지 마세요.**

### Q. 와이파이에 연결됨이라고 나오는데 인터넷을 못 써요.

이 경우는 비밀번호 인증에 성공하고도 인터넷 접속에 문제가 생긴 상황일 수 있습니다. IP·DNS·회선·포털 로그인 등을 확인해야 하므로 비밀번호를 반복해서 바꾸는 것은 우선순위가 아닙니다.

### Q. 회사 노트북의 인증서를 삭제하고 재연결해도 되나요?

회사·학교 관리형 네트워크는 인증서, 계정, 관리 프로필에 따라 동작합니다. 승인 없이 지우면 복구가 어려울 수 있으므로 IT 담당자에게 문의하세요.
